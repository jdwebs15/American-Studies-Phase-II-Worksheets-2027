# American Studies Phase II — 2027

Twelve content blocks with 40-question supported Introductions, 30-question independent Reviews, and preserved Vocabulary supplements. Each worksheet owns its unique questions inside its HTML; shared files provide behavior only.

Review tickets require 30/30 first answers correct in one run. Intro tickets require corrected mastery, preserving first scores. Earlier runs and cumulative attempts remain recorded.

Read `AUDIT-REPORT.md` for measured results and validation limits, `REBUILD-SUMMARY.md` for preview/deployment instructions, and `standards/ALIGNMENT-BLUEPRINT.md` for exact Ohio expectations and question mappings. Live Apps Script compatibility has not been tested. No production deployment is included.
